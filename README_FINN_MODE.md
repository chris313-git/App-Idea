# Finn Mode PWA

A personal iPhone-first training app for the 12-week Finn Bálor-inspired athletic cut.

## Launch
The app lives in `/finn-mode`. For GitHub Pages, publish the repository and use the Pages URL ending in `/finn-mode/`.

## Version 1
- Today workout dashboard
- RPE/load/reps logging
- Editable exercise prescriptions
- 12-week navigation
- Wednesday + Sunday rest days
- Run section and interval timer
- Bodyweight/waist logging
- Nutrition targets
- LocalStorage data; no account or cloud database

Training logs stay on the device in this version.

## iPhone
Open the published `/finn-mode/` page in Safari → Share → Add to Home Screen → Open as Web App → Add.
